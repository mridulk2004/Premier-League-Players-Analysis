## Project Overview

This project presents a comprehensive data analysis of Premier League players' performance during the 2024-2025 season using SQL. The project demonstrates SQL skills, including database setup, data cleaning, exploratory data analysis, and actionable insights for sports analytics.

---

## Objectives

- Set up a Premier League players database for the 2024-2025 season.
- Clean and preprocess player, team, and match data for high data quality.
- Analyze metrics like goals, assists, appearances, positions, and disciplinary records.
- Use SQL to answer advanced analytical questions about players, teams, and performance trends.

---

## Project Structure

1. **Database Setup**  
   - Run `PREM_ANALYSIS.sql` to create and populate all necessary tables (players, teams, matches, statistics).

2. **Data Cleaning**  
   - Remove or correct incomplete or erroneous records.

3. **Exploratory Data Analysis**  
   - Query total goals by player, average assists per match, appearances, and disciplinary statistics.

4. **Analytical Queries**  
   - Find top goal scorers and assist providers.
   - Identify players with most appearances.
   - Compare teams based on player performance statistics.
   - Analyze disciplinary records (yellow/red cards) and their effects.

---

## Findings and Insights

- **Standout Players:** Identified top performers by goals and assists.
- **Seasonal Trends:** Recognized performance patterns across matches and teams.
- **Disciplinary Data:** Examined player behavior and its impact on team outcomes.
- **Detailed Reports:** Generated summary and trend reports for coaching and fan engagement.
